## Your starting point

Nothing exists yet. Scaffold a fresh Vite + React + TypeScript project
with Tailwind CSS set up (whatever the current recommended setup for
Tailwind + Vite is). Bring Primitiv into this project however makes the
most sense to you — its styled copy-in components enhanced with Tailwind
utilities where useful, or its plain unstyled components styled entirely
with Tailwind, or a mix that varies page to page. It's your call; there's
no house answer for this combination yet, so make a reasonable one and
note in `NOTES.md` which way you went and why, especially if you hit any
friction between the two systems' styling (things like which one seems to
"win" when both try to set the same property).

## Brand

If you end up using Primitiv's own theming at all, your client's brand
colour is `#0a7755` — use it the same way you'd feed a brand colour into
any themeable library. If you end up driving colour entirely through
Tailwind's own configuration instead, that's a legitimate choice too — say
which you did in `NOTES.md`.
