# `badge` — registry entry

The artefacts `primitiv add badge` resolves and copies into a consumer repo —
the **status/count chip** from RFC 0021. Like `kbd`, `badge` has **no
headless `@primitiv-ui/react` counterpart**: `<Badge>` carries zero
behaviour, so it ships entirely from the registry.

## What it does

`Badge` renders a `<span>` chip attached to another element (an icon, an
avatar) or sitting beside a heading — read-only, never interactive. Two
treatments:

| Variant | Emphasis | Tokens | Typical use |
|---|---|---|---|
| `label` (default) | low | `feedback/{tone}/soft/*` | a status word, e.g. "Shipped" |
| `counter` | high | `feedback/{tone}/solid/*` | a notification count, e.g. "3" |

Four semantic tones (`success`/`warning`/`info`/`danger`), sized `xs`–`xl`
(default `md`); `data-density` scales each size further.

**Circularity is structural, not a variant.** `min-inline-size` is pinned to
the same `badge/{size}/height` token that drives `block-size`, so short
content (a 1-2 character count) is forced into a true circle while longer
content (a status word) naturally widens into a pill — independent of which
`variant` is set.

## Usage

```tsx
import { Badge } from "@/components/badge";

<Badge tone="success">Shipped</Badge>
<Badge tone="info">Beta</Badge>
<Badge tone="danger" variant="counter">3</Badge>
```

A badge overlapping a host icon (e.g. a notification bell) needs no special
handling beyond normal absolute positioning in the consumer's own markup —
the circle/pill shape and centred label are guaranteed by the component
itself.

## Files

| File | Authored? | Role |
|---|---|---|
| `contract.json` | **authored** | The styling contract — the `.primitiv-badge` root class, the `tone`/`variant`/`size` modifiers, and the `--primitiv-badge-*` custom properties. |
| `styles.css` | **authored** | The canonical default theme: the chip box + tone×variant colour matrix, in `@layer primitiv.base`/`primitiv.variants`. |
| `styles.scss` | **authored** | `styles.css` plus a trailing `$`-alias block, one `$primitiv-badge-<prop>` per custom property. |
| `badge.recipe.ts` | **authored** | `cva("primitiv-badge", { variants: { tone, variant, size } })` — mirrors `kbd`'s recipe shape. |
| `badge.tsx` | **authored** | The `<Badge>` wrapper. Hand-written (there is no primitive to generate from): a thin `asChild` (Slot) wrapper that renders a `<span>`, or the consumer's own element. |

Because there is no headless primitive, `badge.tsx`/`badge.recipe.ts` are
**not** generated by `primitiv-emit` and carry **no drift-guard test**
(contrast the generated wrappers, D53). `badge.tsx` is type-checked in CI by
`scripts/check-registry-types.mjs` like every other registry wrapper.

## Tokens

`badge` consumes two new families added alongside this component:

- **`feedback/{tone}/{soft,solid}/{background,foreground}`** (Intent) — four
  tones × two treatments. `soft` (→ `variant="label"`) is a low-emphasis
  tint; `solid` (→ `variant="counter"`) is a high-emphasis fill, with a
  per-tone AA-audited foreground (black for success/warning/info, white for
  danger — see the Figma "Badge" component description for the full contrast
  record and the success/info white-foreground attempt that was reverted for
  failing AA).
- **`badge/{size}/{height,padding-inline,font-size,gap}`** (Context) — sizing,
  density-scaled. `gap` is reserved for a future leading-indicator slot; the
  current single-child (label-only) anatomy doesn't consume it.
- **`badge/{size}/{label-height,label-padding-inline}`** (Context) — a second,
  taller height + wider padding-inline pair, applied via a
  `.primitiv-badge--label.primitiv-badge--{size}` compound selector so it
  only ever re-points the `variant="label"` shape's `--primitiv-badge-height`
  / `-padding-inline`. Descenders (`g`, `j`, `p`, `q`, `y`) were crowding the
  pill's bottom curve at the tighter density/size combinations — worst at
  Dense — under the shared `badge/{size}/height`, so `label` gets a bit more
  vertical room than `counter`. Deliberately **not** shared with `counter`:
  counter's circularity comes from `min-inline-size` clamping to that same
  shared `badge/{size}/height`, and digits have no descenders, so bumping the
  shared token would have inflated the counter circle for no visual reason.

Typography is Khand SemiBold (`--primitiv-font-family-heading` +
`--primitiv-font-weight-semibold`), matching the Figma build; line-height is
a literal `1` (no token — a small cap-trimmed chip needs a tight line box,
not a type-scale value).
