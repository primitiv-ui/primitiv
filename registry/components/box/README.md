# `box` — registry entry

The artefacts `primitiv add box` resolves and copies into a consumer repo —
the **escape hatch** layout primitive from RFC 0022. Like `prose`, `box` has
**no headless `@primitiv-ui/react` counterpart**: `<Box>` carries zero
behaviour, so it ships entirely from the registry.

## What it does

`Box` is a bare polymorphic element with no visual opinion — the simplest
possible registry component. It exists so a consumer has *something* to
attach a custom property or a one-off inline style to, instead of reaching
for a raw `<div>` (which reads as "this wasn't meant to carry system
styling"). The only rule it carries is `box-sizing: border-box`, so a
consumer's own padding/border math is predictable.

## Usage

```tsx
import { Box } from "@/components/box";

// A one-off styling attachment point:
<Box style={{ "--primitiv-space-space-16": "1.25rem" }}>
  <Card />
</Box>

// Or your own semantic element via asChild:
<Box asChild>
  <section aria-label="Summary">…</section>
</Box>
```

## Files

| File | Authored? | Role |
|---|---|---|
| `contract.json` | **authored** | The styling contract — the `.primitiv-box` root class. No modifiers, no custom properties. |
| `styles.css` | **authored** | The canonical default theme: `box-sizing: border-box`, in `@layer primitiv.base`. |
| `styles.scss` | **authored** | Byte-identical mirror of `styles.css` — `box` owns no `--primitiv-box-*` tokens, so there is no `$`-alias block to derive. |
| `box.recipe.ts` | **authored** | A base-only `cva("primitiv-box")` — the class as a recipe, for parity with the other entries. |
| `box.tsx` | **authored** | The `<Box>` wrapper. Hand-written (there is no primitive to generate from): a thin `asChild` (Slot) wrapper that renders a `<div>`, or the consumer's own element. |

Because there is no headless primitive, `box.tsx`/`box.recipe.ts` are **not**
generated by `primitiv-emit` and carry **no drift-guard test** (contrast the
generated wrappers, D53). `box.tsx` is type-checked in CI by
`scripts/check-registry-types.mjs` like every other registry wrapper.

## Tokens

None. `box` owns no design tokens — see RFC 0022 §3.
