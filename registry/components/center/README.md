# `center` — registry entry

The artefacts `primitiv add center` resolves and copies into a consumer
repo — the centring layout primitive from RFC 0022 (build-order step 2).
Like `box`, `center` has **no headless `@primitiv-ui/react` counterpart**:
`<Center>` carries zero behaviour, so it ships entirely from the registry.

## What it does

`Center` is a single- or both-axis Flexbox centring box. It carries no
sizing opinion — like `box`/`stack`/`spacer`, it forces no width or height,
only the alignment behaviour; a consumer sizes the box itself (it fills its
parent's inline space in normal block flow, or gets an explicit size via
`style`/`className`).

- `axis` — `"both"` (default), `"horizontal"`, or `"vertical"`. The
  uncentred axis stays content-driven (`flex-start`), never stretched to
  fill it.

## Usage

```tsx
import { Center } from "@/components/center";

<Center style={{ blockSize: "100vh" }}>
  <Spinner />
</Center>

<Center axis="horizontal">
  <Logo />
</Center>
```

## Files

| File | Authored? | Role |
|---|---|---|
| `contract.json` | **authored** | The styling contract — the `.primitiv-center` root class and the `--both`/`--horizontal`/`--vertical` modifiers. No custom properties. |
| `styles.css` | **authored** | The canonical default theme: the Flexbox alignment rules, in `@layer primitiv.base`/`primitiv.variants`. |
| `styles.scss` | **authored** | Byte-identical mirror of `styles.css` — `center` owns no `--primitiv-center-*` tokens, so there is no `$`-alias block to derive. |
| `center.recipe.ts` | **authored** | `cva("primitiv-center", { variants: { axis } })`. |
| `center.tsx` | **authored** | The `<Center>` wrapper. Hand-written (there is no primitive to generate from): a thin `asChild` (Slot) wrapper that renders a `<div>`, or the consumer's own element. |

Because there is no headless primitive, `center.tsx`/`center.recipe.ts` are
**not** generated by `primitiv-emit` and carry **no drift-guard test**
(contrast the generated wrappers, D53). `center.tsx` is type-checked in CI by
`scripts/check-registry-types.mjs` like every other registry wrapper.

## Tokens

None. `center` owns no design tokens — see RFC 0022 §3.
