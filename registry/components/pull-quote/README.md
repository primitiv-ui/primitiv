# `pull-quote` — registry entry

The artefacts `primitiv add pull-quote` resolves and copies into a consumer
repo — the large editorial quote from RFC 0023 / RFC 0012 D13. Like `prose`,
`pull-quote` has **no headless `@primitiv-ui/react` counterpart**:
`<PullQuote>` carries zero interactive behaviour, so it ships entirely from
the registry.

## What it does

`PullQuote` is a large, centred editorial quote — distinct from `Blockquote`:
no accent bar, no attribution line. Its size rides the existing `heading/*`
Context scale rather than a new type ramp:

| `size` | Heading step |
|---|---|
| `xs` | `heading/h5` |
| `sm` | `heading/h4` |
| `md` (default) | `heading/h3` |
| `lg` | `heading/h2` |
| `xl` | `heading/h1` |

`marks` (default `false`) toggles the decorative open-quote mark above the
text. **No new tokens** — everything rides the existing `heading/*` scale and
`content/*` colours (RFC 0012 D13).

### The mark is the real Figma asset, not a CSS character

`PullQuote.tsx` inlines the **actual outlined vector** from the "Pull Quote /
Mark" component (Hoefler Text Black `“`, flattened to a path — RFC 0012
D13), extracted verbatim via the Figma Desktop Bridge from node `589:9055`
(the `md` size instance) — not a font character or CSS-generated glyph. All
five Figma size variants (mark heights 18/22/28/32/38px, xs→xl) are a
uniform scale of the same path, so one `<path>` at the `md` viewBox covers
every step; the stylesheet sizes it with `--primitiv-pull-quote-mark-height`, a
`calc()` of one literal ratio per size (`0.75`–`0.875`, derived from the real
asset's own mark-height ÷ heading-font-size proportion — not a constant
multiplier, since the source asset isn't a fixed fraction of its heading step)
against `--primitiv-pull-quote-font-size`.

It has to be that token and not an `em`: `font-size` lands on
`.primitiv-pull-quote__text`, not the root, so an `em` on the mark — a *sibling*
of the text — resolved against the root's inherited **body** size and left the
mark frozen at 12–14px for every `size`. With the calc it tracks both `size` and
`[data-density]`, and reproduces Figma's mark heights exactly at comfortable:
18/22/28/32/38 for xs–xl. Colour is `currentColor`, driven by `--primitiv-pull-quote-mark-color`
(`content/muted`), matching the Figma fill exactly.

### One platform difference from the Figma build

The Figma set is a fixed 480px-wide frame with 24px padding on every side —
both unbound raw literals (no token binding on either, confirmed via the
Figma Desktop Bridge), i.e. the padding is the gutter *inside that specific
480px card*, not an independent typographic spacing decision. Both are
**deliberately not reproduced here** — `Container`'s max-width scale doesn't
exist yet (RFC 0022 §4 defers it) — so `PullQuote` takes no width or padding
opinion; a consumer constrains it with their own layout (or `Container`,
once it lands, at which point the 24px padding is worth revisiting
alongside it, since it only makes sense paired with a width).

## Usage

```tsx
import { PullQuote } from "@/components/pull-quote";

<PullQuote marks size="lg">
  A large editorial pull quote.
</PullQuote>
```

## Files

| File | Authored? | Role |
|---|---|---|
| `contract.json` | **authored** | The styling contract — the `.primitiv-pull-quote` root class, the `--xs…--xl` modifiers, and the `--primitiv-pull-quote-*` custom properties. |
| `styles.css` | **authored** | The canonical default theme: the centred layout + heading-scale type + decorative mark, in `@layer primitiv.base`/`primitiv.variants`. |
| `styles.scss` | **authored** | `styles.css` plus a trailing `$`-alias block, one `$primitiv-pull-quote-<prop>` per custom property. |
| `pull-quote.recipe.ts` | **authored** | `cva("primitiv-pull-quote", { variants: { size } })`. |
| `pull-quote.tsx` | **authored** | The `<PullQuote>` wrapper. Hand-written (there is no primitive to generate from): renders the optional mark — an inline SVG holding the real Figma vector path — and the quote text. |

Because there is no headless primitive, `pull-quote.tsx`/`pull-quote.recipe.ts`
are **not** generated by `primitiv-emit` and carry **no drift-guard test**
(contrast the generated wrappers, D53). `pull-quote.tsx` is type-checked in CI
by `scripts/check-registry-types.mjs` like every other registry wrapper.

## Tokens

`pull-quote` reuses the existing `heading/h1`–`h5` type scale, `content/primary`
(quote text) and `content/muted` (mark), plus existing `space/*` primitives
for the fixed per-size mark↔quote gap (a typographic proportion of the size
axis, constant across density modes, mirroring Blockquote's
`quote/body-gap/{size}` treatment). No new *design* tokens were added for
this component (RFC 0012 D13); `--primitiv-pull-quote-mark-height`'s five
per-size `em` ratios are literals derived directly from the real Figma
asset's own geometry, not a token reference — there's no existing token
family for a bespoke asset's aspect proportion.
