# `spacer` — registry entry

The artefacts `primitiv add spacer` resolves and copies into a consumer repo —
the **flex-growing filler** layout primitive from RFC 0022. Like `prose`,
`spacer` has **no headless `@primitiv-ui/react` counterpart**: `<Spacer>`
carries zero behaviour, so it ships entirely from the registry.

## No Figma counterpart

There is deliberately **no Figma component set** for this primitive, and none is
planned — confirmed by a sweep of every page in the Primitiv Design System file
(the `---- LAYOUT ----` section holds only `Divider`). It renders no visual
affordance of its own: everything it does is layout behaviour that Figma
expresses natively through auto-layout, so a component set would encode
nothing a designer could use. There is therefore nothing to cross-check its
tokens or variant axes against — RFC 0022 (§5, §8, §9) is its whole spec, and
the `Figma` column of `ROADMAP.md` reads `—` for exactly this reason.

## What it does

`Spacer` is a blank `flex: 1 0 0` element for pushing flex siblings apart —
toolbar left/right groups, card footers, nav bars. It has no props beyond the
ones every `<div>` accepts, and is only meaningful as a direct child of a
flex (or grid) container, such as `Stack` with `direction="row"`. It is
decorative by default (`aria-hidden="true"`), since it carries no content —
pass `aria-hidden={false}` to override.

## Usage

```tsx
import { Spacer } from "@/components/spacer";
import { Stack } from "@/components/stack";

<Stack direction="row" gap="sm">
  <Logo />
  <Spacer />
  <Button>Sign in</Button>
</Stack>
```

## Files

| File | Authored? | Role |
|---|---|---|
| `contract.json` | **authored** | The styling contract — the `.primitiv-spacer` root class. No modifiers, no custom properties. |
| `styles.css` | **authored** | The canonical default theme: `flex: 1 0 0`, in `@layer primitiv.base`. |
| `styles.scss` | **authored** | Byte-identical mirror of `styles.css` — `spacer` owns no `--primitiv-spacer-*` tokens, so there is no `$`-alias block to derive. |
| `spacer.recipe.ts` | **authored** | A base-only `cva("primitiv-spacer")` — the class as a recipe, for parity with the other entries. |
| `spacer.tsx` | **authored** | The `<Spacer>` wrapper. Hand-written (there is no primitive to generate from): a thin `<div>` with the spacer class and a decorative default `aria-hidden`. |

Because there is no headless primitive, `spacer.tsx`/`spacer.recipe.ts` are
**not** generated by `primitiv-emit` and carry **no drift-guard test**
(contrast the generated wrappers, D53). `spacer.tsx` is type-checked in CI by
`scripts/check-registry-types.mjs` like every other registry wrapper.

## Tokens

None. `spacer` owns no design tokens — see RFC 0022 §3.
